❓ Operator guide — what do these mean?
Equals eq
The field value matches the entered value exactly.
Not Equals ne
The field value is anything except the entered value.
Contains contains
The field value includes the entered text anywhere within it.
Like like
Partial / wildcard-style pattern match on the field value.
Greater Than gt
The field value is greater than the entered value — best for numbers or dates (e.g., Priority).
Less Than lt
The field value is less than the entered value — best for numbers or dates.

💡 Contact Method (phone) searches are format-tolerant — dashed (215-555-1234) and dashless (2155551234) numbers match either way.

ℹ️ About Description Search — what is this for?

Description Search finds tickets by the words inside their description — ideal when you remember what an issue was about but not a specific ticket number or field value.

🔤 How it works
Enter one or more words. A ticket matches only if its description contains all of them — matched independently, in any order.
🎫 What it searches
Live Incident (IR) or Service Request (SR) descriptions, selected with the Ticket Type toggle below.
🔎 Example
Typing printer jam returns tickets whose description mentions both printer and jam.
💡 When to use it
Best for keyword recall. For meaning-based matches that don't rely on exact words, use Semantic Search instead.
